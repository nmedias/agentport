# @agentport/ui

The component library of the Agentport design system: shadcn/ui primitives re-clothed in the
Agentport token layer (`src/styles/`), one folder per component under `src/components/ui/`, each
with its `.tsx`, `.stories.tsx`, `.spec.tsx` and barrel. Browse it with `npm run storybook` from
the workspace root; `npx nx test @agentport/ui` runs the unit specs + story tests.
